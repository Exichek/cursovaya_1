# Курсовая работа №1

Приложение для анализа банковских транзакций из Excel-файла.

## Возможности проекта

В рамках проекта реализуются:

- формирование данных для веб-страниц;
- анализ банковских транзакций;
- поиск транзакций;
- формирование отчетов;
- получение курсов валют и стоимости акций через сторонние API.

## Структура проекта

- `data/operations.xlsx` — данные банковских операций;
- `src/utils.py` — вспомогательные функции;
- `src/views.py` — формирование данных для веб-страниц;
- `src/services.py` — сервисы анализа и поиска;
- `src/reports.py` — функции формирования отчетов;
- `src/main.py` — точка входа в приложение;
- `tests/` — тесты проекта;
- `user_settings.json` — пользовательские настройки.

## Установка

Клонируйте репозиторий:

```bash
git clone https://github.com/Exichek/cursovaya_1.git
cd cursovaya_1

```

Установите зависимости:

```powershell
poetry install
```

Создайте файл с переменными окружения:

```powershell
Copy-Item .env.example .env
```

Заполните API-ключи в созданном файле `.env`.
